Computación en la Nube

Azure Static Web Apps y Oracle Cloud Compute VM

Comparativa práctica entre el alojamiento de aplicaciones web estáticas en Azure Static Web Apps y el aprovisionamiento de un servidor web en Oracle Cloud Infrastructure (OCI) con Oracle Linux y Node.js.

Ver características técnicas

Azure Static Web Apps

Servicio administrado que compila y publica sitios web estáticos y aplicaciones frontend modernas directamente desde un repositorio Git (como GitHub), integrando flujos de trabajo CI/CD y distribución global.

  • Despliegue automático mediante GitHub Actions.
  • Certificados SSL administrados y red de entrega global.
  • Ideal para HTML, CSS, JavaScript y frameworks modernos.

Oracle Cloud Compute VM (Linux Web Services)

Máquina virtual en la nube (Always Free con forma VM.Standard.E2.1.Micro y Oracle Linux) donde se configura manualmente el sistema operativo, el servidor Node.js, el firewall, las reglas de red y el servicio systemd.

  • Acceso completo al sistema operativo vía SSH (usuario opc).
  • Servidor HTTP en Node.js escuchando en el puerto 3000.
  • Regla de ingreso stateless en la VCN y arranque automático con systemd.
