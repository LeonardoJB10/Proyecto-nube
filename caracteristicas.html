Características técnicas

Especificaciones de infraestructura, red, seguridad y automatización observadas en Azure Static Web Apps y en la práctica de Oracle Cloud Compute VM.

Especificaciones del laboratorio Oracle Cloud Compute VM

Componente Configuración / Detalle técnico
Sistema operativo Oracle Linux 7.9 (imagen base de instancia Always Free)
Forma de cómputo (Shape) VM.Standard.E2.1.Micro (1 OCPU, 1 GB de memoria, 0.48 Gbps de ancho de banda)
Autenticación y acceso Par de llaves SSH (id_rsa / id_rsa.pub en ~/.ssh) y conexión vía Git Bash con usuario opc
Entorno de ejecución Node.js instalado mediante repositorios oracle-nodejs-release-el7 y oracle-release-el7
Aplicación web (index.js) Servidor HTTP nativo en 0.0.0.0:3000; responde Hello World en GET /greeting y Healthy en otras rutas
Firewall y red (VCN) Apertura de puerto 3000/tcp con firewall-cmd y regla de ingreso Stateless (CIDR 0.0.0.0/0, puerto destino 3000, protocolo TCP)
Persistencia y arranque Servicio startwebserver.service en /etc/systemd/system/ habilitado con systemctl enable

Ventajas

  • Azure Static Web Apps: despliegue continuo ágil, bajo mantenimiento de servidor y escalabilidad automática para contenido estático.
  • Oracle Cloud VM: control total del entorno Linux, personalización de servicios y capa Always Free para prácticas de infraestructura.

Desventajas

  • Azure Static Web Apps: limitado a arquitecturas estáticas/serverless sin administración directa de un SO completo.
  • Oracle Cloud VM: mayor curva de configuración manual (llaves SSH, firewall, seguridad de red y demonios del sistema) y recursos limitados en el nivel gratuito.
